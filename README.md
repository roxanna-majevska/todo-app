# Todo App

Todo App is a simple web application created with HTML and JavaScript.

The application allows users to create, complete and delete tasks. Tasks are stored in the browser using local storage.

## Project structure

```text
todo-app/
├── docs/
│   └── project-description.md
├── src/
├── tests/
├── .gitattributes
├── .gitignore
└── README.md
```

The files have the following purposes:

- `docs/` contains additional project documentation.
- `src/` contains the source code for the application.
- `tests/` contains tests for the application.
- `.gitattributes` defines how Git handles different file types.
- `.gitignore` defines files and directories that Git should ignore.
- `README.md` contains information about the project.

## Getting started

No installation or build process is required.
